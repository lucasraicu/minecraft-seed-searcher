# Approved Pillar 1 size calibration

Objective: meaningful 4096/8192 rankings with the established 2048 balance.
Budgets are user-frozen: total1250, OW845, luxury265, Nether140. No personal
predictor, scoring or OpenMP changes. Nether square1024 and its rules unchanged.

1. Inventory existing natural observations and separately labeled qualified
controls. Bind raw inventories to native/source/model identities and coverage.
Only compare centers whose full requested square was surveyed. Unknown features
are unresolved, never zero. Hold out worlds using digest(world_id) modulo5 ==0;
no feature-driven resplitting. Report sampling/selection limitations explicitly.
2. Reuse existing candidate-center and exact square/biome helpers for the larger
OW halves2048/4096, fixed Nether half512 and floor(x/8) projection. Preserve
2048 native refined-center behavior. Do not substitute sparse public grid
anchors for claims about globally best centers; describe candidate coverage.
3. Measure count distributions, current-threshold saturation and joint-floor
qualification at each size. Select integer floors and count schedules from the
development cohort, preserving feature point ceilings and monotone gains. Use
2048 empirical rarity as the reference; do not fabricate universal floors if the
cohort has no reliable qualifying examples. Record insufficient evidence as a
failed activation gate, then collect only bounded additional existing-seed data.
4. On untouched holdouts report qualification rate with sample counts, feature
and group contribution distributions, cap saturation and ranking changes. Check
all budgets, monotonicity, same-center dimensions, negative-coordinate projection
and exact2048 parity. Keep Nether/luxury point formulas fixed while reporting
whether their realized ranking influence differs by world size.
5. Codex reconciles independent Gemini High findings against actual evidence.
Freeze the calibration artifact (cohort, split, floors, thresholds, metrics,
source identities, revision and retention allocation). Larger boards activate
only with passing evidence and a clear versioned UI score explanation.

Assignments: Codex owns evidence/calibration and integration; Gemini critiques
this procedure and later audits the frozen result. Automation and UI proceed
independently, with larger-board activation explicitly gated. Main risks are
selection bias, sparse rare-structure samples and incomplete survey extents.
No GPU/custom database, terrain generation, new personal run or unbounded search.
