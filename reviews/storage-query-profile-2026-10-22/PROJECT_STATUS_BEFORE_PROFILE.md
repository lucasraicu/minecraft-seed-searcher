Authority by scope:

- Current personal behavior: source, versioned configuration and
  [master blueprint](../MASTER_SEED_BLUEPRINT.md). Preserve exact predictor
  semantics when optimizing; passing predictor tests is not game verification.
- Public pilot query/storage vocabulary: [system specification](../PUBLIC_CATALOG_SYSTEM_SPEC.md),
  [player policy](catalog/PUBLIC_CATALOG_PLAYER_POLICY.md) and
  [contract artifacts](catalog/v1/README.md). The private research implementation
  reads these contracts; public capability activation remains off.
- Four-pillar organization and staged engineering contract:
  [reconciled public master plan](catalog/proposals/Public_Catalog_Master_Plan.md). It preserves
  SQLite-first staging and does not change runtime contracts or authorize later
  campaigns. [Master platform proposal](specs/MASTER_PLATFORM_SPECIFICATION.md)
  supplies preset/record product intent; conflicting physical schemas, performance
  claims and certification examples are superseded by the reconciled plan.
- Operational approval/state: [handoff](../CODEX_HANDOFF.md). Past completion
  banners, numerical scenarios and this status map are not implementation approval.

For public queries, all Required predicates must match the same anchor and keep
their hard boundaries. Preference utility may be soft; it never relaxes Required
filters. Observations and summaries must carry coverage/version/evidence status;
unknown is not absent. Planned border **side lengths** are 2048, 4096 and 8192.

Fleet seeds/sec, retention percentages, compressed sizes, query latency and hosting
costs in vision documents are unvalidated until a reproducible artifact identifies
the source/build, hardware, policy, input population, measured stages and retained
outputs. Raw placement, rejected full-seed inputs and complete useful public
records are different units. Do not multiply speculative stage speedups together.
