# Test navigation

Keep existing locations and invocation forms. Sibling imports, `__file__` root
discovery and CJS `__dirname` assumptions must be checked before relocation.
Pytest already discovers `tests/` through `pyproject.toml`.

For a fresh checkout, follow the [native install instructions](../README.md#native-build-and-provenance)
before native-dependent tests. `setup.py` builds both `_native` and
`_blueprint_batch`; compiling only `native/build.py` does not provide the second
extension. Compiled binaries are generated locally and are intentionally excluded
from Git. Use temporary output roots for fixture tests, keeping live runs intact.

Catalog: `.venv/bin/python -m pytest tests/catalog`

Node checks use `node tests/<name>.cjs` from the repository root. No new runner,
fixture split or collection behavior is introduced by this index.
